### What I work on

Document intake and extraction, summarization, semantic matching, RAG. Shipped an AI

**8,500+ documents, 384 companies and 490 drivers**.

**🛡️ Agents with guardrails**
Multi-agent orchestration, function calling, propose-then-approve flows, immutable audit
logs, PII redaction. If an agent can touch something that matters, a human approves it first.

**📊 Measured, not vibes**

AI sprint generation, ticket extraction with dependency graphs, voice-to-text incident
reporting, offensive-language moderation, document digitization.
